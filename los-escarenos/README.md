# Los Escareños

Family static pages live under **`/los-escarenos/`** in the [caravan.landondahle.com](https://github.com/lardahle/caravan.landondahle.com) repo. One folder per person; tools ship as you spec them.

## Structure

| Path | Person |
|------|--------|
| `/los-escarenos/` | Family landing |
| `/los-escarenos/victor-sr/` | Víctor (Sr.) — terapia del habla, tablero |
| `/los-escarenos/alejandra/` … | Placeholders |

## Preview locally

From the **caravan.landondahle.com** repo root:

```bash
npx --yes serve -l 4400
```

- http://127.0.0.1:4400/los-escarenos/

Deploys with the same **FTP** GitHub Action as the rest of this site.
